# HyperHex

I am planning to create a new project, which is HyperHex. In 2023 Databricks AI Summit in San Francisco, I got a chance to deliver a talk on hexagonal hierarchical geospatial indexing. Now, I would want to take it to a four-dimensional thing so that the hexagonal spherical tiles into the space can act as autonomous vehicle pathways for traffic control of future autonomous vehicles. I tried putting all my thought process into a research paper. I am attaching that here. Now I would like to take an open source project like hyper hex. And then create a project for this.

Aerial drones and UTM — shape HyperHex around a research simulator for 4D airspace reservations, with a CesiumJS experiment workbench.

The interactive small-scale demonstration — build a compact scenario that shows 4D reservations, replanning, and conflicts in the CesiumJS workbench.
